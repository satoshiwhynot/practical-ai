# Hammerhead Cutaway

### A mechanical shark you can take apart.

**[Watch Satoshi's demonstration on X ↗](https://x.com/satoshiwhynot/status/2119444847614431315)**

An adaptation of the open-source [Cutaway](https://github.com/Nyxera0x/cutaway) project by Nyxera0x and whaleyxbt.

## What changes in Satoshi's version

- Paired sliding hammer lobes with eighteen armour plates.
- Relocated eyes with separating lens rings and an iris.
- Adjusted camera targeting.
- Revised HUD branding, animation labels and timeline controls.

This is a visual model, not a validated mechanical design.

## Where the source comes from

The original piranha example and rendering kit come from Cutaway, which is MIT-licensed. Satoshi's changes adapt that base into the HX-1 hammerhead.

This folder is a showcase and attribution record. The editable source bundle and rendered video are not included here. Use the linked demonstration to inspect this version, and the upstream repository to explore the original toolkit.
