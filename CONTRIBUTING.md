# Contributing

A useful contribution makes a workflow easier to follow or easier to check.

- State the task and the reader it helps.
- Attach sources to factual claims.
- Label fictional data and hypothetical examples.
- Describe what you ran, including the command and observed result.
- Keep credentials, private material and generated exports out of the repository.
- Preserve third-party attribution.

For a correction, open an issue with the file, the problem and supporting evidence. For a change, keep the pull request focused on one workflow.
