# Provenance and credits

This collection packages Satoshi's existing writing and working material into reusable kits. Prepared on 2026-11-12.

| Material | Origin and scope |
| --- | --- |
| AI film | Ten original companion prompts from Satoshi's [published Claude Code/Codex + Seedance guide](https://x.com/satoshiwhynot/status/2118633855150182759). The kit does not claim a completed paid-generation run. |
| Content studio | Original positioning worksheet, editorial prompts and review process from the one-person creative-team material. Financial examples are hypothetical. |
| Coding agents | Companion task and evidence templates with fictional CSV fixtures, adapted for this collection. Expected outputs are a contract, not a measured application result. |
| Second Brain | Original practice-vault structure and session prompts. The newsletter sources and their decisions are fictional. |
| Behavioral parity | Companion templates adapted from the REA worked example. The original article's test counts, costs and timings were illustrative. No target app, replacement or measured parity score is included. [Published follow-up](https://x.com/satoshiwhynot/status/2119499552449564998). |
| Product motion | Planning and review templates derived from Satoshi's product-motion material. The original separate Blender reference is not included here. |
| Hardware planning | Templates derived from Satoshi's [voice-hub guide](https://x.com/satoshiwhynot/status/2119948201780191347). No circuit or PCB design is included. |
| Hammerhead | Satoshi's published adaptation of [Cutaway](https://github.com/Nyxera0x/cutaway), originally by Nyxera0x and whaleyxbt. The showcase identifies the changes and links the demonstration; no upstream source is redistributed here. |

## References

- [REA](https://github.com/morluto/rea): analysis tooling behind the source article's investigation workflow.
- [Claude Code](https://code.claude.com/docs/): check current installation and capabilities before using the prompts.
- [Cutaway](https://github.com/Nyxera0x/cutaway): upstream 3D project. Its code retains its own license.

Model and brand names identify tools discussed; they do not imply affiliation. Historical articles may reference model versions whose access must be checked in your own account.
