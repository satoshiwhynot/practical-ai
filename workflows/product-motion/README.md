# Product motion: make the explanation visible

**Template kit.** Plan a short product film before building or rendering the scene.

Derived from Satoshi's product-motion workflow. This folder contains planning files and review prompts; it does not include the separate Blender scene, render runner or model access.

1. Fill [BRIEF.md](BRIEF.md) with the product, audience, message and available assets.
2. Use [PROMPTS.md](PROMPTS.md) to make a shot plan.
3. Put one purpose and one visible action in each row of [SHOT-MAP.csv](SHOT-MAP.csv).
4. Review a still for every cut.
5. Render a rough cut only after framing and continuity are approved.
6. Use [REVIEW.md](REVIEW.md) at actual playback size.

For a real product, base geometry and technical claims on supplied material. A concept render is a visual reference, not evidence that the device can be manufactured.
