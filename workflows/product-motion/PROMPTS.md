# Product-motion prompts

## Plan the shots

```text
Read BRIEF.md and the supplied product material.
Propose five shots for a 15-second film. For each, state what the viewer
learns, what visibly changes, camera position and a still to review.
Keep unverified product details marked UNKNOWN. Do not render yet.
```

## Build one review still

```text
Build only the approved first shot using the available geometry.
State which tool and version you can actually use.
Save a review still, identify any approximated geometry and compare it
with the supplied references. Do not start a full animation render.
```

## Review the rough cut

```text
Watch the complete rough cut at delivery size.
Check framing, continuity, text readability, pacing and whether each cut
explains its intended point. Attach a frame or timestamp to each issue.
Separate required fixes from optional polish.
```

## Revise

```text
Apply only the approved revisions. Keep the previous scene/version.
List the changed shots and expected effect. Render review stills before
starting a full export. Record the actual tool and render settings.
```
