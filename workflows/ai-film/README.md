# AI film: from idea to final cut

**Template kit.** Make the story work in text, review stills, then generate motion for approved shots.

[Read the guide on X](https://x.com/satoshiwhynot/status/2118633855150182759) · [Copy ten production prompts](PROMPTS.md)

## Start in five steps

1. Set the premise, duration, aspect ratio, intended viewer and spending limit.
2. Use [PROMPTS.md](PROMPTS.md) to produce a story, shot list and continuity rules.
3. Review a still for each shot. Fix the character, composition and props before motion.
4. Generate one short test shot. Record its actual cost and decide whether to continue.
5. Assemble approved clips, inspect transitions and export a rough cut before another paid revision.

## Files

- [PROMPTS.md](PROMPTS.md): ten detailed production prompts from the guide.
- [SHOT-PLAN.csv](SHOT-PLAN.csv): fillable shot list.
- [COST-LEDGER.csv](COST-LEDGER.csv): estimates and actual charges kept separate.

The kit does not include model access, an API integration or a completed generated film. Use the tools you actually have and check current prices before paid work.
