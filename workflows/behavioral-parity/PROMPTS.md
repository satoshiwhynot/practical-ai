# Two bounded jobs

## Investigation

```text
Investigate [FEATURE] in [AUTHORIZED APP PATH]. Fix the build and
environment first. Follow one request from the exposed interface to its
output. Save inputs, ordered outputs and evidence locations.
Separate observations, inferences and unknowns. Create a versioned
behavioral spec. Do not implement a replacement yet.
```

## Implementation

```text
Implement the supplied spec using only permitted files in this workspace.
Do not access the target app or investigation artifacts.
Preserve the interface, ordering, pagination and defined error categories.
List ambiguities instead of inventing behavior. Run development cases and
preserve mismatches. Do not inspect reserved evaluation cases.
```

These prompts describe roles. File and tool permissions establish the actual separation.
