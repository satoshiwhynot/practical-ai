# Coding-agent workbench

**Task and evaluation kit.** Define the result before asking an agent to change your app.

The practice task is a CSV importer. An application is not bundled.

1. Copy the kit into a separate working copy of your existing app.
2. Adapt [TASK.md](TASK.md) and fill [RUNBOOK.md](RUNBOOK.md) with real commands.
3. Use [PROMPTS.md](PROMPTS.md) for baseline inspection, implementation and review.
4. Run the [fixtures](fixtures/) against [EXPECTED.json](EXPECTED.json) in the actual app.
5. Record observations in [EVIDENCE.md](EVIDENCE.md), leaving unrun checks marked **NOT RUN**.

The fictional fixtures are a practice contract for this kit. Expected results are not a claim that an importer has passed them.
