# Three planning prompts

## Scope

```text
Read SPEC.md. Reduce this prototype to one interaction we can prove with
the hardware already available. List missing requirements and the smallest
software test. Do not choose a custom PCB or order parts.
```

## Components

```text
For the agreed interaction, propose components with actual datasheet links.
Record voltage, interfaces, physical constraints and unresolved compatibility
questions. Distinguish a candidate from a verified choice. Do not invent stock
availability, prices or electrical compatibility.
```

## Handoff

```text
Prepare a revision handoff with requirements, approved decisions, BOM,
actual design files if present and test evidence. Mark unrun checks NOT_RUN.
List the decisions needed before purchase or manufacturing submission.
```
