# Hardware planning kit

**Planning templates.** Scope one interaction before choosing a custom board.

Derived from Satoshi's [voice-hub guide](https://x.com/satoshiwhynot/status/2119948201780191347).
This kit contains no circuit, PCB, manufacturing package or validated electrical design.

1. Fill [SPEC.md](SPEC.md) for hardware you already have.
2. Use the [scope prompt](PROMPTS.md), then record accepted choices in [DECISIONS.md](DECISIONS.md).
3. Prove the software interaction before committing to a custom board.
4. Populate [BOM.csv](BOM.csv) with actual parts and verified specifications.
5. Fill [TEST-PLAN.csv](TEST-PLAN.csv) with real observations; leave unrun checks marked **NOT_RUN**.

Purchasing, electrical design and manufacturing require separate decisions and checks.
